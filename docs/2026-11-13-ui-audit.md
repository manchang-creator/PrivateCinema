## 5. 审计发现 / 风险

1. `:hover` 悬浮态无法在 WebView 合成指针下稳定触发，相关效果（进度条点亮、移除按钮显现）按标准 CSS 交付；建议真机鼠标手测一次。
2. P3 窄屏断点 620px 低于窗口 `MinWidth=960`，桌面端实际不会触发，属为未来窄窗/移动 Web 预留；桌面端验证需临时下调 MinWidth。
3. 自动轮播仅作用于 Hero 与首个在线大卡区，且已具备悬浮暂停与 reduced-motion 停用，风险可接受。
4. 变更源码中无 `console`/`TODO`/`debugger` 残留；`desktop/dist/` 未入库（`.gitignore` 已忽略）。
5. 运行环境 `.git` 存在损坏的 `GIT_CONFIG_COUNT/KEY` 环境变量，提交/推送时通过剥离这些变量绕过，未修改仓库配置。
